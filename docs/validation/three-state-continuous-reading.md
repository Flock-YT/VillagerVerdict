# 三状态与持续读取验证

`./gradlew test` 与 `./gradlew runClientGameTest` 均通过。

- 单元测试覆盖未扫描不进入分析、成功空交易读取、人工保留/不保留、最近一次替代记录、附魔升级后红转绿及新格式存储。
- 真实服务器交易包验证附近两名村民首次读取，保留 30 秒冷却后再次读取；一级村民升级时保留旧快照，新增锋利 V 后从红色变为绿色。
- 验证保留、不保留、未扫描三个筛选；主界面开启/暂停同时设置/移除当前世界自启，首次开启仍需确认。
- 无关设置保存保持手动探测运行；全部重置恢复自定义的隐藏标记字段，并清空其他服务器自启和确认记录。
- 320×240 逻辑窗口断言所有设置控件边界，颜色改用单按钮选择器。人工检查英文截图，颜色控件没有越界。
- 回归套件通过库存/菜单安全、职业过滤、多行标记、中英文界面、世界隔离和清理流程。

设置版本 4、世界数据版本 3，不迁移旧开发数据。交易快照只保留交易列表和读取时间；村民等级仍作为实体信息展示。自动读取仍遵守 30 秒冷却、正常可达距离、视线和串行交互条件。
